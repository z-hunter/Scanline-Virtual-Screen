# Scanline Virtual Screen

Reusable virtual screen, CRT renderer, optional xterm source adapter, profiles, overlays, and controlled React settings sections.

The first stable package release is `v1.0.0`. `ScreenProfile.schemaVersion` is versioned independently and is currently `1`.

Entry points:

- `scanline-virtual-screen/core`
- `scanline-virtual-screen/terminal`
- `scanline-virtual-screen/react`
- `scanline-virtual-screen/react/styles.css`

The package is private and consumed from its immutable Git tag. It does not know about Tauri, ConPTY, tabs, storage, or game state.
